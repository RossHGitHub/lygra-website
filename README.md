# Lygra website

Static product preview for Lygra.

Website: https://rosshgithub.github.io/lygra-website/

GitHub Pages serves this repository directly from `main` at `/`. No build or package installation is needed. `.nojekyll` bypasses Jekyll processing.

The beta form posts to FormSubmit. Receiving-inbox activation and a delivery test are required before relying on applications. Do not add credentials to this repository.
